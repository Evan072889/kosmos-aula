# KOSMOS-AULA

### Plataforma educativa interactiva

KOSMOS-AULA es un proyecto educativo que busca incorporar nuevas formas de aprendizaje mediante el uso de herramientas digitales, actividades interactivas y simulaciones.

La plataforma está pensada para estudiantes, docentes y familias, con el objetivo de ofrecer un entorno que facilite el aprendizaje, fomente la participación y permita trabajar diferentes contenidos de una manera más práctica.

## Funcionalidades

### Laboratorio virtual 3D

KOSMOS-AULA incorpora un laboratorio virtual en el que los estudiantes pueden interactuar con diferentes elementos y realizar experimentos de forma simulada.

El objetivo es acercar la experimentación científica al entorno digital y permitir que los alumnos aprendan mediante la práctica.

### Juegos diarios

La plataforma incluye un apartado de juegos y actividades educativas que permite trabajar distintos conocimientos mediante pequeños retos.

Estas actividades buscan reforzar los contenidos y mantener la participación de los estudiantes.

### Adaptación al entorno familiar

El proyecto tiene en cuenta la diversidad lingüística de las familias. El idioma que se utiliza habitualmente en casa puede influir en la comunicación y en el acompañamiento educativo del estudiante.

Por ello, KOSMOS-AULA contempla esta diversidad como parte de su planteamiento.

### Entorno para docentes y familias

La plataforma diferencia los espacios según el tipo de usuario, ofreciendo herramientas y contenidos adaptados a cada perfil.

Los apartados destinados a los estudiantes mantienen sus funcionalidades restringidas para los perfiles que no tienen acceso a ellos.

## Objetivos del proyecto

- Facilitar el acceso a recursos educativos interactivos.
- Fomentar el aprendizaje práctico mediante simulaciones.
- Incorporar la gamificación como herramienta de refuerzo.
- Tener en cuenta las diferentes necesidades del alumnado.
- Facilitar la participación de docentes y familias en el entorno educativo.

## Tecnologías

El proyecto utiliza tecnologías de desarrollo web para implementar la interfaz, las funcionalidades interactivas y los diferentes entornos de aprendizaje.
